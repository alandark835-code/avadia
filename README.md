# avadia
AVADIA

Un lenguaje de programación. Infinitas posibilidades. En español.

Avadia es un proyecto de lenguaje de programación multipropósito diseñado para permitir la creación de software de diferentes categorías mediante una sintaxis en español, moderna, intuitiva y potente.

Su objetivo es ofrecer una alternativa de desarrollo capaz de abarcar desde programas sencillos hasta proyectos de software complejos, combinando facilidad de aprendizaje, flexibilidad, rendimiento y herramientas de desarrollo propias.

Avadia busca construir un ecosistema tecnológico completo que permita desarrollar videojuegos, aplicaciones, páginas web, sistemas, herramientas de inteligencia artificial y mucho más.

🚀 Objetivos del proyecto

Avadia tiene como objetivo convertirse en un lenguaje de propósito general, tomando inspiración de la versatilidad de Python, la potencia de los lenguajes compilados y las herramientas de los entornos modernos de desarrollo.

Entre sus principales áreas de aplicación se encuentran:

- 🎮 Desarrollo de videojuegos: creación de videojuegos 2D y 3D, con sprites, animaciones, físicas, colisiones, sonido, mapas y sistemas de inteligencia artificial.
- 🌐 Desarrollo web: creación de páginas web, aplicaciones web, interfaces, formularios, componentes, servidores y APIs.
- 📱 Aplicaciones móviles: desarrollo de aplicaciones para Android y, en futuras etapas, iOS.
- 🖥️ Software de escritorio: creación de aplicaciones para Windows, Linux y macOS.
- 🤖 Inteligencia artificial: herramientas de automatización, procesamiento de datos, modelos y agentes inteligentes.
- ⚙️ Sistemas y herramientas: creación de utilidades, programas, servicios, herramientas de desarrollo y automatización.
- 📊 Ciencia y datos: cálculos, simulaciones, análisis y procesamiento de información.
- 🔌 Robótica y hardware: integración futura con dispositivos, sensores y sistemas compatibles.

🧠 Filosofía del lenguaje

Avadia busca que programar sea más accesible sin renunciar a la potencia técnica.

Sus principios fundamentales son:

- Sintaxis y palabras reservadas en español.
- Arquitectura modular y extensible.
- Facilidad de aprendizaje.
- Flexibilidad para diferentes tipos de proyectos.
- Rendimiento y optimización.
- Compatibilidad con herramientas y bibliotecas externas.
- Desarrollo multiplataforma.
- Seguridad y manejo claro de errores.

🛠️ Ecosistema Avadia

El proyecto contempla el desarrollo de diferentes herramientas y módulos:

- Avadia Core: núcleo del lenguaje, intérprete, parser, sistema de tipos y futuras capacidades de compilación.
- Avadia Game Studio: herramientas para crear videojuegos 2D y 3D.
- Avadia Web: herramientas para desarrollar páginas y aplicaciones web.
- Avadia Mobile: entorno y herramientas para aplicaciones móviles.
- Avadia Desktop: desarrollo de software de escritorio.
- Avadia AI: herramientas relacionadas con inteligencia artificial.
- Avadia Creator Studio: entorno de desarrollo visual para programar, administrar proyectos, depurar y ejecutar aplicaciones.

📌 Desarrollo y versiones

Avadia se encuentra en desarrollo evolutivo. Cada versión incorpora nuevas capacidades y mejora la arquitectura del lenguaje.

La visión a largo plazo es construir una plataforma de programación completa, con herramientas propias, bibliotecas, documentación, extensiones y soporte para múltiples plataformas.

🎯 Visión

Crear un lenguaje de programación moderno, potente y versátil, donde el español sea el idioma principal de programación y donde los desarrolladores puedan construir prácticamente cualquier tipo de software desde un mismo ecosistema.

AVADIA — Programa sin límites. Crea en español.

## ⚡ Inicio rápido y ejemplo de código

Así de limpio y natural luce un programa escrito en **Avadia** (incluyendo tipado progresivo de la v1.3):

```avadia
// Saludo y tipos progresivos en Avadia
crear nombre: texto = leer("¿Cómo te llamas? ")
crear nivel: entero = 1

funcion saludar(usuario, puntos)
    mostrar "¡Hola, " + usuario + "! Bienvenido a Avadia."
    mostrar "Nivel inicial: " + puntos
fin

saludar(nombre, nivel)
```

### 📥 Instalación rápida (Windows)

1. Asegúrate de tener instalado **Python 3.10 o superior** (con `Add Python to PATH` y `tcl/tk` activados).
2. Clona este repositorio o descarga la última versión desde la sección de [Releases](https://github.com).
3. Ejecuta `instalar_avadia.bat`.
4. Abre una nueva terminal y verifica la instalación:

```bash
avadia --version
```

### 💻 Comandos principales

```bash
avadia programa.av              # Ejecutar un programa
avadia --verificar programa.av  # Analizar tipos y semántica sin ejecutar
avadia --editor                 # Abrir Avadia Creator Studio (IDE visual)
avadia --nuevo juego mi_juego   # Crear un proyecto desde plantilla
avadia --ayuda                  # Ver todos los comandos disponibles
```
